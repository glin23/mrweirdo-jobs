## 目标
能替拍板人本人真投出去（第一判据）。方向：美国 AI 视频公司，实习 + 2027 应届全职。

## 模式：即找即投
- 用户说「跑 N 个」即开始；N = 投成 N 个，超当天上限只投到上限并说明。
- 每次运行：名单公司优先 → 接上次游标轮转 → 去重闸 → 打分 → 合格当场投 → 投满 N 或看满 N×10 停 → 3 行报告（投成的「公司·岗位」/ 没投成原因 / 新岗是否不够数）。
- 不存岗位库。本地只留：投递账本、看过记录、扫描游标。

## 去重（硬指标：连跑两次零重复投递；已判不合适的零重复打分）
- 合格但本次额度已满没投的岗，下次运行允许重新打分（不另存「合格未投」队列——拍板人否掉了岗位库）。lead 裁决 2026-09-25，依据拍板人原话只针对重复投递。
- 岗位身份双钥匙：平台+岗位编号 或 公司+标题，任一命中即同岗。
- 投过（含 unknown）永不再投；看过不合适 60 天不再看，JD 变或简历/方向变则重看。
- 同公司 60 天最多投 2 次。新岗不够如实少投，不降标准凑数。

## 投递规则
- 按分高低投，不设圈层比例。梦想公司投前给拍板人过目答案，其余看到就投。
- JD 明写不办签证 / 只要公民的跳过。
- 只投 Greenhouse + Ashby；Lever 暂停。

## 2026-09-26/27 补充拍板（取代上文冲突处）
- **分工**：目标公司（21 家 AI 视频名单）程序只扫、只打分、只列「公司·岗位·链接」，拍板人自己手投、自己写开放题；非目标 = Greenhouse/Ashby 上 AI 应用类创业公司的增长/市场/社媒/运营/产品岗，程序自动投走量（sourcing_mode = watchlist_first）。
- **岗位类型**：实习 + 2027 应届全职；应届全职 = 非资深普通全职且 JD 未写明 ≥3 年；≥3 年跳过。地点只美国与美国远程。
- **表单**：事实类小题按简历 / 已答事实填保守真实值，不逐题问；开放式问答题等拍板人一起写。
- **提交**：简历上传完成后才点；提交按钮只点一次，唯一例外是页面当场报出新的必填缺项、补完再交一次（总点击 ≤2）；判不出一律 unknown（算可能已投），由 lead 查 Gmail 确认邮件后用 `correct` 兜底。
- **平台反垃圾 / 机器人检测**：被拦即终局（platform_spam_flagged，不占名额），不重交、不做任何绕过。
