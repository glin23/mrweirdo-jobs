## 模式：即找即投
- 用户说「跑 N 个」即开始；N = 投成 N 个，超当天上限只投到上限并说明。
- 每次运行：名单公司优先 → 接上次游标轮转 → 去重闸 → 打分 → 合格当场投 → 投满 N 或看满 N×10 停 → 3 行报告（投成的「公司·岗位」/ 没投成原因 / 新岗是否不够数）。
- 不存岗位库。本地只留：投递账本、看过记录、扫描游标。

## 去重（硬指标：连跑两次零重复投递；已判不合适的零重复打分）
- 合格但本次额度已满没投的岗，下次运行允许重新打分（不另存「合格未投」队列——拍板人否掉了岗位库）。lead 裁决 2026-09-25，依据拍板人原话只针对重复投递。
- 岗位身份双钥匙：平台+岗位编号 或 公司+标题，任一命中即同岗。
- 投过（含 unknown）永不再投；看过不合适 60 天不再看，JD 变或简历/方向变则重看。
- 同公司 60 天最多投 2 次。新岗不够如实少投，不降标准凑数。
